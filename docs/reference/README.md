# Fontes históricas preservadas

O [arquivo fontes-originais.zip](fontes-originais.zip) preserva os bytes recebidos antes das edições:

- `repositorio-inicial/`: os 21 arquivos versionados no commit inicial.
- `anexos-recebidos/`: seis documentos de Doc. Inicial e o PDF fornecido.
- `manifest.json`: caminho, tamanho e SHA-256 de cada uma das 28 entradas de fonte.

O manifesto é metadado do arquivo histórico; não é o formato de backup do futuro aplicativo. Versões antigas contêm danos, instruções superadas e afirmações de PASS incorretas. Consulte-as somente para proveniência ou comparação, não como instruções vigentes do Cursor.

A fonte atual é a [documentação oficial consolidada](../ATLAS_DE_INTERESSES_DOCUMENTACAO_OFICIAL.md), com [decisões](../DECISIONS.md) e [questões abertas](../OPEN_QUESTIONS.md). [RECOVERY_LOG](../RECOVERY_LOG.md) explica cada reconciliação. O PDF visual também está disponível diretamente em [design](../design/atlas-design-system.pdf).
